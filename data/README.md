# ESCO Taxonomy Data Directory

Place the ESCO Skills CSV in this folder:
- **Filename**: `skills_en.csv`
- **Download URL**: https://esco.ec.europa.eu/en/use-esco/download
- **Dataset**: Skills pillar -> English -> CSV format
- **Expected Columns**: `conceptUri`, `preferredLabel`, `altLabels`, `description`, `skillType`
